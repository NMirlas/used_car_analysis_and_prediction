# Used Car Market Analysis

A machine learning project for used-car price prediction and depreciation simulation, with an interactive Power BI dashboard.

## Overview

This project builds an end-to-end pipeline to:

- clean and normalize raw used-car listings
- validate brand/model pairs with an LLM-assisted checker
- engineer pricing features
- train and compare regression models
- predict listing-level fair value
- simulate future price changes as vehicles age

## Dashboard

Power BI dashboard file included in this repository:

`Dashboard/used_car_dash&pred.pbix`

To view it, open the `.pbix` file with Power BI Desktop.

The dashboard is designed to cover:

- market price distributions
- brand-level comparisons
- model prediction quality
- depreciation simulation by vehicle profile

## Pipeline

### 1. Preprocessing

Script: `preprocessing.py`

Main tasks:

- normalize `brand` and `model`
- export unique brand-model pairs for validation
- apply corrections from validated mapping
- engineer features such as:
  - `car_age`
  - `price_per_hp`
  - `price_per_liter`
  - `age_bucket`
  - `price_bucket`
- filter invalid/outlier rows
- save processed datasets

### 2. LLM-Assisted Brand/Model Validation

Scripts: `validate_pairs.py`, `brand_model_validator.py`

Main tasks:

- send `(brand, model)` pairs to OpenRouter (`gpt-4o-mini`)
- fix spelling errors and brand-model mismatches
- save corrected pairs to `Data/pairs/brand_model_corrections.csv`

### 3. Model Training and Evaluation

Script: `regression_model.py`

Models compared:

- Linear Regression
- Ridge Regression
- Random Forest
- XGBoost

Evaluation metrics:

- RMSE
- R²

Current best model in this project: XGBoost.

### 4. Depreciation Simulation

Script: `price_simulation.py`

Main tasks:

- train a final XGBoost pricing model
- simulate future prices by increasing `car_age`
- export simulation output for dashboard analysis

## Setup

### Requirements

- Python 3.10+

Install dependencies:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install pandas numpy scikit-learn xgboost requests
```

## Configuration

`validate_pairs.py` uses OpenRouter.

Set your API key before running validation:

```bash
export OPENROUTER_API_KEY="your_key_here"
```

Important: do not commit API keys.

## How to Run

Run scripts in this order:

```bash
python3 preprocessing.py
python3 validate_pairs.py
python3 preprocessing.py
python3 regression_model.py
python3 price_simulation.py
```

Why preprocessing runs twice:

- first run creates `brand_model_pairs.csv`
- validation creates corrections
- second run applies corrections into processed outputs

## Current Results

Reported project benchmark:

- R²: ~0.73
- RMSE: ~27,100 ILS

Interpretation: the model explains about 73% of price variance in this dataset.

## Limitations

The current dataset does not include some high-impact pricing features:

- mileage
- trim/package level
- vehicle condition
- accident history

Including these features can improve model quality.
